# Courier

 Game Details:
 - This is a game which player transports a cursed statue and tries to stay alive.
 - Different mechanic of the game: different driving mechanics from the usual.
 - Shader Lab is used for realistic rain effect on windows.
   
 Development Details:
 - Made for "SCREAM JAM 2025" game jam.
 - Game jam had 1 week time for submitting files however this project is developed in 2 weeks.
 - Shader Lab is learned.
 - No AI support is used in any development or designing process.
